## Projects

### Smart AI TaskFlow App

The gap was clear: managing tasks through a chat interface should feel natural, not clunky. Hafsa built a fullstack chatbot application that merges conversation with task management—users don't fill out forms, they just talk. The backend runs on Agentic AI and FastAPI, processing what the user says and turning intent into action. The frontend, built with Next.js and connected through Spec-Kit Plus, presents that back to the user in a clean interface. The result is a system that feels less like software and more like working with an assistant who understands your workflow.

### Physical AI & Humanoid Robotics

Robotics documentation is often a wall of text—dense, intimidating, pushing away the curious. Hafsa decided to flip that: build an interactive book that brings humanoid robotics to life on screen. She used Next.js on the frontend, Python on the backend, and Spec-Kit Plus to wire it together. Rather than static paragraphs and diagrams, visitors explore through interaction—they can engage with concepts, not just read about them. The result transforms robotics from a distant specialization into something discoverable and real.

### BurgerStack

An e-commerce site lives or dies by its checkout experience. Hafsa built BurgerStack as a fully responsive website that guides customers from browsing to purchase—add-to-cart, checkout confirmation, every step clear and affirmed. The interface is customizable and readable at any screen width because Tailwind CSS and responsive design principles do the work. Built with Next.js, BurgerStack shows how the right technical choices and UX patterns work together: the user always knows where they are in the flow, so friction disappears.
